# Python Strings and Tuples Assignment

## 📌 Problem Statement
This assignment focuses on understanding Python string operations and tuple manipulation, including concatenation, slicing, built-in methods, and tuple operations.

---

## 🎯 Key Tasks & Features

### 1. String Operations
* **Concatenation:** Joining user input strings to build custom sentences.
* **Slicing & Indexing:** 
  * Extracting first, last, first 5, and last 11 characters.
  * Reversing strings using `[::-1]`.
  * Extracting specific sub-strings (e.g., `"Python"`).
* **String Methods:** 
  * Case conversions using `.upper()`, `.lower()`, and `.capitalize()`.
  * Counting character occurrences using `.count()`.
  * Replacing target words using `.replace()`.

### 2. Tuple Operations
* **Tuple Creation & Concatenation:** Combining distinct tuples into `t_combine`.
* **Repetition:** Multiplying tuple elements for repetition.
* **Accessing Elements:** Indexing specific elements and slicing first/last 3 items.

### 3. Practical Mini Projects
* **Retail Inventory Manager:** Demonstrates tuple immutability (fixed categories) vs list mutability (dynamic items).
* **Contact Directory:** 2D List manipulation including `append()`, `pop()`, and sorting algorithms.
